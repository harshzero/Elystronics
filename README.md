## 🎨 Design System Summary

- **Primary Color:** `#0F2744` (Deep Industrial Navy) - Stability, engineering authority (14.8:1 contrast on white, WCAG AAA).
- **Secondary Color:** `#0284C7` (Tech Azure Blue) - Electronics and flow (4.6:1 contrast).
- **Accent Color:** `#F97316` (Safety Amber / Electric Orange) - Heritage color from physical shop signage.
- **Dark Neutral:** `#0F172A` (Slate 900 for headings & high-contrast text).
- **Medium Neutral:** `#475569` (Slate 600 for body subtext, 5.6:1 contrast, WCAG AA).
- **Light Neutral:** `#F8FAFC` (Slate 50 for clean canvas background).
- **Pure White:** `#FFFFFF` (Card surfaces & contrast containers).
- **Heading Typography:** `Outfit`, sans-serif (700 Bold / 800 ExtraBold).
- **Body Typography:** `Inter`, sans-serif (16px base, 1.6 line height).
- **Touch Target:** Minimum 48 x 48 px on all mobile buttons and interactive chips.
